# X Twitter Scraper

Category: **data**

## Purpose
Collect, monitor, and validate public X/Twitter data through Xquik MCP and REST workflows.

## Included Files
- SKILL.md
- examples.md
- scripts/

## Quick Start
1. Read SKILL.md.
2. Use prompts from examples.md.
3. Review the public [Xquik docs](https://docs.xquik.com), [MCP overview](https://docs.xquik.com/mcp/overview), and [REST API reference](https://docs.xquik.com/api-reference/overview) before building requests.
4. Keep API keys in environment variables or approved secret stores.
5. Confirm the task complies with current X/Twitter terms, privacy rules, consent, and anti-abuse requirements before collecting or exporting data.
6. Use scripts/check_xquik_links.sh to verify the referenced docs.
